# AGENTS.md — epic-harness adapter for non-Claude agents

contract: generated by `epic-new` at the epic root / read by any AI agent that does not run the Claude Code hook+skills (Codex, Cursor, Copilot CLI, …) / regenerated when ACTIVE changes

An epic is active in this workspace. Before doing ANY work here:

1. Read `.claude/epics/ACTIVE` — first line is the epic slug, following lines are the
   member repo names. If your working repo is not listed, this epic does not apply to you.
2. Read `.claude/epics/<slug>/charter.md` — the **Non-negotiables** section is binding
   for you verbatim. The roles table defines your role and what you may write.
3. Read `.claude/epics/<slug>/state.md` (where the work stands) and the row of the
   active slice in `plan.md`. Do not read the whole plan or all journals.
4. Create YOUR journal file before working: `.claude/epics/<slug>/journal/
   <YYYY-MM-DD>-<HHMM>-<role>[-<unique-token>].md` (copy the section structure of any
   existing entry). Append a unique token if the name already exists — never reuse a file.
5. Write discipline:
   - **executor**: write ONLY your own journal file; put ledger/state/gate suggestions
     in its Proposals section.
   - **coordinator**: fixed handoff order — journal → ledger → gated-actions →
     plan.md statuses (evidence required) → `state.md` rewritten LAST (max 40 lines,
     `updated: <ISO ts> by coordinator`).
6. Before exit, finalize your journal file: Done (with commit hashes), Discovered,
   Decisions, Proposals, Next. Work that is not in a journal did not happen.

Slice statuses flip to done only with evidence (verify-command output or commit hash).
Human-only actions live in `gated-actions.md` (G-NN) — never execute them yourself.
